# 1.概述
![传输层总览](../../images/cs/cs%20net/3传输层总览.png)


![传输层流程示意](../../images/cs/cs%20net/3传输层流程示意.png)

应用层向传输层传输报文段，传递给传输层，接收方将报文段重组成报文，传递给应用层。在向下方面，传输层需要尽可能完善网络层服务的不足，比如利用rdt完善网络层中的可靠性不足。网络层基于IP，传输层基于进程，更为细分，称为复用解复用功能，复用即将所有进程的TCP/UDP报文从一个服务端发出，解复用即所有报文均由一个接收端接收，再转发给相应进程。

# 2.多路复用解复用
TCP流程：应用层向下发送socket，TCP端将源端口、目标端口和报文信息封装成TCP报文，并伴随着源IP与目标IP传递给网络层。在接收端，将接收数据拆分成TCP报文，结合源端口与目标端口，查询socket，发送给对应进程。

UDP流程：大致流程一致，只是传输数据要依照UDP报文形式.。

# 3.无连接传输UDP
![UDP报文细节](../../images/cs/cs%20net/3UDP报文细节.png)

头部占比小，TCP20个字节，其中校验和称作EDC，在接收时会计算接收EDC与报文中的EDC对比，如果有误则一定传输错误，如果没有误也不能肯定一定没有错误，称为残存错误。

![数据块格式](../../images/cs/cs%20net/3数据块格式.png)

具体操作，将数据部分，头部部分分割成16bit的小块，然后每个小块相加，最后取反码，成为EDC，在接收端，**将整个UDP**，包括EDC部分按照16bit规则全部相加，因为EDC来自于反码，所以在没有传输错误的情况下最后结果应该全为1
