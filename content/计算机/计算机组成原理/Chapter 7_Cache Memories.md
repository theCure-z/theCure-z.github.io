# Cache Memories

![高速缓存示意图](https://cdn.nlark.com/yuque/0/2026/png/58377233/1776924209655-add448c4-2e27-4540-8865-db566687d69e.png)

高速缓存位于 CPU 中,由硬件控制

![](https://cdn.nlark.com/yuque/0/2026/png/58377233/1776924322452-f59f937e-cfdb-4ac0-b860-19c0cef6ddfe.png)

高速缓存组成:由$ 2^s$个组组成,每个组中有$ 2^e$行,每行中有$ 2^b $字节,总大小$ 2^{s+e+b} $字节,每行中有指示位 v 代表行是否使用,tag 表示行代表的数据

# 读取数据

![](https://cdn.nlark.com/yuque/0/2026/png/58377233/1776924692374-6ddce85e-412d-4343-a4eb-851afbab4362.png)

CPU 请求数据时,将数据分为 t+s+b,首先按照 s 位对应查找组,再在该组中寻找有没有 tag 相同的行,最后将 b 位组成数组索引在$ 2^b $个字节中索引数据

![](https://cdn.nlark.com/yuque/0/2026/png/58377233/1776925468014-212f8499-da2e-451f-85c4-1f97a79e54fa.png)

在同一组中进行对 tag 的搜索,如果有效位和 tag 同时匹配,则成功,可以知道,$ 2^e $决定了一组中同时存在的缓存行,由于存在比较算法,行数越多复杂性越高
块的作用是分摊时间成本,当一个数据不在缓存中时,硬件选择从内存中取出一块的数据而不是所需的字节,根据空间局部性,在需要的数据周围的数据利用率较高,所以通过取出一块数据来抹平读写内存的时间

# 写入数据 

两种思路

1. 一旦高速缓存更改立即向内存写入数据(时间成本高)
2. 当高速缓存中的某一行决定被擦除时,如果该行更改了,向其对应的内存写入数据

如果更改的数据没有在高速缓存中呢

1. 立即擦除新行,将数据移至缓存中,向缓存写入数据(如果数据需要频繁修改很友好)
2. 直接向内存写数据
