# 友元函数
使用**friend**关键字，使用在类内，但并不属于类的函数，拥有访问实例对象中**public**和**private**变量的能力

```cpp
class Box
{
   double width;
public:
   friend void printWidth( Box box );
   void setWidth( double wid );
};
 
// 成员函数定义
void Box::setWidth( double wid )
{
    width = wid;
}
 
// 请注意：printWidth() 不是任何类的成员函数
void printWidth( Box box )
{
   /* 因为 printWidth() 是 Box 的友元，它可以直接访问该类的任何成员 */
   cout << "Width of box : " << box.width <<endl;
}
```

# 重载函数与重载运算符
在同一个作用域内，可以声明同名函数，但是其形参必须不同

```cpp
class printData
{
   public:
      void print(int i) {
        cout << "整数为: " << i << endl;
      }
 
      void print(double  f) {
        cout << "浮点数为: " << f << endl;
      }
 
      void print(char c[]) {
        cout << "字符串为: " << c << endl;
      }
};
```



重载运算符使用**operator**关键字以及后面等待重载的运算符号构成，重载运算符与函数一致，带有返回类型和参数列表

```cpp
      Box operator+(const Box& b)
      {
         Box box;
         box.length = this->length + b.length;
         box.breadth = this->breadth + b.breadth;
         box.height = this->height + b.height;
         return box;
      }
```

# 显式类型转换
static_cast<目标类型>(表达式)，用于在编译前完成类型转换

```cpp
//基本类型转换
int i = 42;
double d = static_cast<double>(i); // int → double
char c = static_cast<char>(65);    // int → char ('A')

//派生类到基类转换
class Base {};
class Derived : public Base {};
Derived* d = new Derived();
Base* b = static_cast<Base*>(d); // 安全，编译器允许

//void与具体类型转换
int i = 10;
void* vp = &i;
int* ip = static_cast<int*>(vp); // void* → int*
```

# 堆与栈内存
栈内存适用于任何普通声明，变量周期在一个{}内，在{}外自动销毁

堆内存使用new关键字，返回该类型指针，内存销毁需要手动，且分配内存有时间代价，但堆空间比栈空间大

# New
```cpp
int* b = new int[50]; // 使用new创建数组必须使用delete[]
delete[] b;

// 二者唯一区别在于，new会默认调用构造函数
Entity* e = new Entity(); // 即使是new Entity也会调用构造函数，但不会对内置类型进行初始化
Entity* e = (Entity*)(malloc(sizeof(Entity)));

//placement new 在已分配的内存上调用构造函数
Entity* e = (Entity*)(malloc(sizeof(Entity)));
new(e) Entity(); // 构造函数不能直接使用e->Entity()调用，只能通过placement new调用
e->~Entity(); // 可以直接使用析构函数
free(e);
```

# 智能指针

```cpp
{
	std::unique_ptr<Entity> entity = std::make_unique<Entity>();
	entity->foo();
}
// unique_ptr会自动在作用域结束时完成delete释放行为
// 缺点，不能当作参数传入函数，因为在函数作用域结束后会销毁，
// 导致主函数中的指针指向未定义的内存空间
```

```cpp
{ std::shared_ptr<Entity> e0;
	{
		std::shared_ptr<Entity> entity = std::make_shared<Entity>();
		e0 = entity;
	}
}
// shared_ptr存在一个指针控制内存块，他记录了当前内存被多少个指针指向
// 当指针指向这块内存的个数为0时，系统自动删除该内存
// 在上面的例子中，在小括号结束时，不会删除内存，因为e0还没有被移除栈帧
// 只有在大括号外，没有指针指向内存，内存自动移除
```

# 拷贝构造函数

```cpp
class Entity{
private:
	char* m_buffer;
	int Size;
public:
	Entity(const Entity& other)
		: Size(other.Size)
	{
		m_buffer = new char[Size + 1]
		memcpy(m_buffer, other.m_buffer, Size + 1)
	}
}
// 使用单纯赋值Entity e1 = Entity e2的后果
// 如果类中存在指针，当某个实例销毁后，释放指针所指向的内存
// 会导致剩下的实例中的指针指向未定义空间
```

# constexpr

```cpp
//constexpr关键字使表达式在编译时能够直接计算
constexpr int size = 10; 

constexpr int square(int x) {
    return x * x;
}

//编译时直接调用，但要求函数是constexpr
constexpr int tmp = square(5); 
//运行时再调用
int tmp = square(3); 
```

| 特性 | const | constexpr |
| --- | --- | --- |
| 修饰变量 | 运行时只读 | 编译时常量 |
| 修饰函数 | 不能 | 可在编译时求值 |
| 初始化 | 运行时/编译时 | 必须编译时确定 |
| 适用场景 | 防止修改 | 性能优化、模板元编程 |
