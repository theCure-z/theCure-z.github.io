# dpkg

| -c --contents：显示某个deb内包含哪些文件 |
| --- |
| -S --search：搜索已安装的指定软件包 |
| -L --listfiles：显示软件包关联安装的文件 |
| -s --status：查询指定软件包状态 |

# chmod

**chmod [对象ugoa][+-=][权限rwx] 文件**

| 对象：用户u，组g，其他人o，所有人a |
| --- |
| 权限：读r，写w，执行x |
| 数字表示法：r=4，w=2，x=1，rwx=7，rw-=6，r--=4，--x=1，---=0 |
| -R --recursive：递归处理子文件 |
| -v：显示执行详细过程 |
| -c：成功之后显示详细执行过程 |

# g++

**g++ [选项] [源文件] **

| -o：指定输出文件，默认a.out |
| --- |
| -c：编译文件为a.o目标文件但不链接 |
| -std=：指定c标准版本 |
| -L：添加库文件搜索路径 |
| -g：包含调试信息 |
| -I：指定头文件路径 |
| -l：链接指定库 |

# CMakeLists

| cmake_minimum_required(VERSION <version>)：指定cmake最低版本要求 |
| --- |
| project(<project_name> [<language>...])：定义项目名称和使用语言 |
| add_executable(<target> <source_files>...)：定义生成的可执行文件和其源文件 |
| add_library(<target> <source_files>...)：定义生成的静/动态库和源文件 |

| link_directories(${Boost_LIBRARY_DIRS})：设置库文件目录 |
| find_package(OpenCV REQUIRED [PATHS /path/to/opencv])：查找库并指定路径 |
| target_include_directories(TARGET target_name<br/>                          [BEFORE | AFTER]<br/>                          [SYSTEM] [PUBLIC | PRIVATE | INTERFACE]<br/>                          [items1...])：为生成文件指定头文件目录 |

# wget

**wget [参数] [URL] [对象]**

| --no-proxy：禁止使用代理 |
| --- |
| -nd：不要创建目录 |
| -T：设置最长等待时间 |
| -L：添加库文件搜索路径 |
| -x：强制创建目录 |
| -O：设置下载至本地的文件名 |
| -c：继续下载中断的文件，支持断点续传 |
| -r：递归下载URL中的所有链接 |
| -b：后台下载 |
| -y：自动确认下载 |
| -P：指定下载目录 |
