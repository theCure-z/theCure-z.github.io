# /bin

**基本二进制文件/应用**

# /sbin

**系统二进制文件/应用，只有系统管理员可以使用**

# /boot

**包含操作系统需要的一切，存放bootloader**

# /dev

**设备存放的地方，unix规定一切皆文件，例如一个硬盘会显示成/dev/sda1，通常是应用和驱动使用的文件夹**

# /etc

**系统配置存储的地方，例如apt的source存储在/etc/apt/apt/source.list**

# /lib

**存储库文件的地方，为bin和sbin使用**

# /mnt

**存放硬盘挂载的地方**

# /opt

**存放从供应商手动安装软件**

# /proc

**存放关于每个进程的相关信息，包括计算机相关信息比如/proc/cpu/info /proc/uptime**

# /run

**在RAM中运行的文件，系统重启后消失，存放运行时信息**

# /snap

**存储snap软件包的文件夹**

# /srv

**存放服务器相关信息如web服务器**

# /sys

**系统文件夹**

# /tmp

**临时文件目录**

# /usr

**用户应用程序文件，安装系统运行非必需的已安装应用程序，从源码编译的大多数文件会安装在/usr/local**

# /var

**变量目录，包含预期会增长大小的目录如/var/log /var/crash**

# /home

**每个用户在/home下都会有自己的文件夹，每个用户都只能访问自己的文件夹除非使用管理员，有些人会将home目录挂在不同的分区下，保证重装系统后不会丢失文件**
