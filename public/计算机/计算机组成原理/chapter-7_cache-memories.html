Cache Memories

高速缓存位于 CPU 中,由硬件控制

高速缓存组成:由个组组成,每个组中有行,每行中有字节,总大小字节,每行中有指示位 v 代表行是否使用,tag 表示行代表的数据

读取数据

CPU 请求数据时,将数据分为 t+s+b,首先按照 s 位对应查找组,再在该组中寻找有没有 tag 相同的行,最后将 b 位组成数组索引在个字节中索引数据

在同一组中进行对 tag 的搜索,如果有效位和 tag 同时匹配,则成功,可以知道,决定了一组中同时存在的缓存行,由于存在比较算法,行数越多复杂性越高 块的作用是分摊时间成本,当一个数据不在缓存中时,硬件选择从内存中取出一块的数据而不是所需的字节,根据空间局部性,在需要的数据周围的数据利用率较高,所以通过取出一块数据来抹平读写内存的时间

写入数据

两种思路

  1. 一旦高速缓存更改立即向内存写入数据(时间成本高)
  2. 当高速缓存中的某一行决定被擦除时,如果该行更改了,向其对应的内存写入数据

如果更改的数据没有在高速缓存中呢

  1. 立即擦除新行,将数据移至缓存中,向缓存写入数据(如果数据需要频繁修改很友好)
  2. 直接向内存写数据
